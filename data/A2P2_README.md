# A2P2 - A Privacy-Constrained Adaptive Inference Framework for On-Device Multimodal AI Under Dynamic Energy and Thermal Budgets

**Track:** Track 2  
**Application:** In-vehicle AI assistant in EVs under battery and thermal budgets

This dataset is synthetic, generated by gen_author2.py with seed 2048. It must be described as synthetic in any publication.

## Simulated scenario

An in-vehicle multimodal assistant in 800 EVs handles navigation, charging planning, cabin control, driver monitoring, messaging and diagnostics requests. A heuristic field controller chose local full model, local quantized model, secure (TEE-attested) cloud offload or deferral under privacy, thermal, battery and network conditions. Each row logs context, action, and realised outcomes - suitable for outcome modelling and off-policy evaluation of a better controller.

## How it was generated

Ambient temperature is seasonal and diurnal. NPU temperature = ambient + load + highway/charging heat. Signal strength drives RTT nonlinearly. Logging policy is stochastic but context-dependent (privacy 3 never offloads; hot or low-SoC devices prefer offload/quantize), giving overlap for off-policy learning. Latency: local = work x (420 or 170 ms) x (1 + 1.8 sigmoid((T-85)/4)) x (1+0.6 cpu); offload = 2 RTT + work x 60 + crypto overhead; deferred 3-30 s; lognormal(0,0.6) noise plus 10% stalls (x2-6). Energy, temperature rise, quality and privacy exposure are action-dependent. 3-5% noise, 1-3% missing in 3 columns, ~0.7% outliers in 2 columns.

## Target / label column(s)

`deadline_met` (binary); regression outcomes `latency_ms`, `energy_j`, `response_quality`; constraint `privacy_exposure_score`. When predicting outcomes, use context + `inference_action` only.

## Suggested experiments

1. Outcome models: predict latency_ms and energy_j given context+action (GBM vs linear); R2/MAPE.
2. Off-policy evaluation of a learned controller (IPS / doubly-robust) maximising deadline_met and quality subject to privacy_exposure = 0 for privacy_level >= 2 and energy budget.
3. Thermal stress test: subset with npu_temp_c > 85; compare deadline-hit rate of policies.
4. Pareto analysis of latency-energy-quality per task_type.
